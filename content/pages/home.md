# Welcome to Our React TypeScript Application

This is a sample page created with DecapCMS. You can edit this content through the admin interface.

## Features

- **React 18** with TypeScript
- **DecapCMS** for content management
- **Webpack** for bundling
- **Hot reloading** for development

## Getting Started

1. Visit `/admin` to access the content management interface
2. Create new pages and posts
3. Manage your site settings
4. Upload and organize media files

This page demonstrates how you can create and manage content through the CMS interface.
