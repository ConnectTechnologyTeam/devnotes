# Hello World from DecapCMS!

This is a sample blog post created with DecapCMS. You can edit this content through the admin interface at `/admin`.

## What is DecapCMS?

DecapCMS is a content management system for static site generators. It provides a clean interface for content creators and developers to manage content without touching code.

## Features

- **Git-based workflow** - All content is stored in your Git repository
- **Editorial workflow** - Draft, review, and publish content
- **Media management** - Upload and organize images and files
- **Custom fields** - Define your own content structure
- **Live preview** - See changes before publishing

## Getting Started

1. Navigate to `/admin` in your browser
2. Sign in with your Git provider
3. Start creating and editing content
4. Your changes will be committed to your repository

This post demonstrates how you can create rich content with markdown, images, and metadata through the CMS interface.
